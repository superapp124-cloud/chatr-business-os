# Contributing to CHATR

Before writing code, read `GENESIS.md`. If your change violates it, redesign the change—not the constitution.

From today onward, don't invest time inventing new architecture. Invest it in proving this one works. Every pull request should answer only three questions:
1. Does it help one of the Genesis Capabilities complete real work?
2. Does it reduce Intent Completion Time?
3. Did a real user (or your own dogfooding) reveal the need for it?

If the answer to any of those is "no," it can wait.
