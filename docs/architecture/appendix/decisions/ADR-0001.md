# ADR-0001: The Kernel Architecture Freeze

**Status:** Accepted
**Date:** 2026-07-21

## Context
CHATR OS has evolved from a low-code platform concept into a vision for a comprehensive "Operating System for Enterprise Software". To ensure the platform scales gracefully without requiring continuous architectural rewrites, we need a stable foundational model that completely isolates enterprise truth, execution behavior, UI presentation, and AI reasoning.

## Decision
The CHATR OS Kernel Architecture (as defined in `/docs/architecture`) is now the immutable reference architecture for all future development. 

The Kernel encompasses the 10 Immutable Primitives (Actors, Objects, Relationships, Events, Processes, Policies, Goals, Knowledge) and the Core Services (Time, Semantics, Intelligence, Query, Projection, Versioning, Integration, Evidence).

**The Golden Rule:**
* The Kernel owns truth. 
* The Runtime owns behavior. 
* The Clients own experience. 
* AI owns neither truth nor behavior—it enhances understanding and decision-making.

## Consequences
* **Governance:** Any change to the Kernel architecture requires an ADR describing the problem, alternatives considered, impact on the ontology, and migration strategy.
* **UI Independence:** Business logic can never be placed within React components.
* **AI Independence:** The Intelligence Engine is strictly prohibited from mutating state or accessing data without a curated Evidence Package.
* **Event Sourcing:** The Object Runtime will migrate to an event-sourced architecture; objects will not be mutated silently.

## Migration Strategy
The transition from the legacy `BusinessObjectStore` to the `Object Runtime` will follow the 8-Phase Infrastructure Rollout, replacing infrastructure underneath the UI without breaking existing Client boundaries.
