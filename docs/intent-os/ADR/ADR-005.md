# ADR-005: Five Runtime Architecture

**Status:** Accepted
**Date:** 2026-07-16

## Context
A monolithic kernel becomes unmaintainable as capabilities grow. The system needs clear separation of concerns for observing the world, evaluating policy, executing actions, verifying outcomes, and learning over time.

## Decision
The kernel manages five orthogonal runtimes: Observation, Stewardship, Execution, Verification, and Learning. Every runtime exists only to observe, evaluate, execute, verify, or improve the lifecycle of an Intent Object.

## Consequences
- All inter-runtime communication must occur via the event bus.
- Runtimes can be versioned and replaced independently (ABI_v1).
