# ADR-003: Observation Runtime is Passive

**Status:** Accepted
**Date:** 2026-07-16

## Context
Allowing external signals (webhooks, email, calendar) to trigger executions directly couples observation with action, creating massive security and architectural risks.

## Decision
The Observation Runtime is strictly passive. It may only watch, normalize, timestamp, and emit `world.changed` events. It cannot execute, decide, notify users directly, or change intent state.

## Consequences
- The intent kernel and policy engine are solely responsible for interpreting what an observation means.
- New observation sources can be added without risking unauthorized execution.
