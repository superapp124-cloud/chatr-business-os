# ADR-004: Verification is Mandatory

**Status:** Accepted
**Date:** 2026-07-16

## Context
Execution dispatches a request (e.g., "pay bill"), but does not guarantee real-world completion (e.g., "funds settled"). Optimistic execution leads to silent failures.

## Decision
Verification is a distinct, mandatory stage between Execution and Completion for all capabilities with real-world side effects. The kernel must not treat an intent as COMPLETED until verification passes.

## Consequences
- Requires a dedicated Verification Runtime.
- Lifecycle states decouple `EXECUTING` from `VERIFYING`.
