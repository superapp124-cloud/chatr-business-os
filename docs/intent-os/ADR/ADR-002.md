# ADR-002: Policy Precedes Execution

**Status:** Accepted
**Date:** 2026-07-16

## Context
In early designs, the execution engine would ask "Can I do this?" during execution. This couples policy evaluation with execution and makes system behavior unpredictable.

## Decision
Policy is the law of the OS and always precedes execution. The hierarchy is `User -> Policy -> Intent -> Execution`. The question is never "Can I?", but "Which policy applies?".

## Consequences
- Execution Runtime requires a pre-authorized execution plan.
- The Learning Runtime may propose policy changes, but cannot unilaterally implement them.
