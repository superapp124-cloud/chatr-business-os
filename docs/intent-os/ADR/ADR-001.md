# ADR-001: Intent Object as Primary Kernel Primitive

**Status:** Accepted
**Date:** 2026-07-16

## Context
The system requires a durable abstraction to represent user-authorized responsibilities over time. Treatings intents merely as ephemeral messages or workflow executions fails to capture ongoing lifecycles (e.g., managing a passport renewal or utility bill over years).

## Decision
The `Intent Object` is established as the central, durable data structure of the OS. All runtimes interact with intent objects according to their granted authority. Everything the kernel manages is an Intent Object.

## Consequences
- Requires a strict lifecycle state machine (LIFECYCLE_SPEC_v1).
- Shifts the architecture from reactive automation to persistent stewardship.
